# Agu's RPG

ChatGPTと一緒に育てる、スマホ対応のレトロ風ブラウザRPGです。

Webアプリはこちら: https://ibsg2020jp-crypto.github.io/agus-rpg/

## 現在できること

- タップした場所へ自動移動
- 近くの住人を「調べる / 助ける」で救助
- 敵に触れるとステージ開始時点へ時間が巻き戻る
- スイッチで扉を開閉するギミック
- 3ステージ構成
- スマホ画面に合わせたUI

## ファイル構成

```text
index.html   画面構造
style.css    レトロ風の見た目とスマホUI
game.js      ゲーム本体、ステージ、移動、救助、敵、ギミック
```

## 遊び方

1. Webアプリを開く: https://ibsg2020jp-crypto.github.io/agus-rpg/
2. 「冒険を始める」を押す
3. マップ上をタップして移動
4. 住人やスイッチの近くで「調べる / 助ける」を押す
5. 住人を全員助けるとステージクリア

ローカルで遊ぶ場合は、`index.html` をブラウザで開いてください。

## GitHub Pagesで公開する場合

GitHubのリポジトリ画面で、

`Settings` → `Pages` → `Build and deployment` → `Deploy from a branch`

を選び、`main` ブランチの `/root` を指定すると公開できます。
